# 🔢 Cálculo de Potência com Ruby

Este projeto é um desafio de código desenvolvido como parte do **Bootcamp Formação Ruby Developer** da [DIO](https://www.dio.me/).

## 📋 Descrição do Desafio

O objetivo deste projeto foi criar um script em **Ruby** que:
1.  Recebe 3 números inteiros digitados pelo usuário.
2.  Armazena esses números em um array.
3.  Utiliza o método `.map` para elevar cada número à **3ª potência** (ao cubo).
4.  Exibe o resultado final no console.

## 🛠️ Tecnologias Utilizadas

* **Ruby** (Linguagem de programação)
* **Git & GitHub** (Versionamento de código)
